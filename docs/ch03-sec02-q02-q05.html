先にこの節の約束

  • 2進数の1桁：0＋0＝0、0＋1＝1、1＋1＝0 で繰り上げ1、1＋1＋1＝1 で繰り上げ1
  • 減算は 0−1 のとき左の桁から借りる。借りるとその桁は「2」になるので、2−1＝1
  • この教科書の補数は、足すと1桁増える最も小さな数（nビットなら、足すと 1 のあとに 0 が n 個）
  • 求め方の手順：各ビットを反転して、最後に 1 を足す（桁数は揃えたまま）

問題確認問題2

次の4ビットの2進数を計算する。答えも4ビット。

式10進で見ると
（1）0011(2) ＋ 1001(2)3 ＋ 9 ＝ 12
（2）0111(2) ＋ 0001(2)7 ＋ 1 ＝ 8
（3）1010(2) − 0010(2)10 − 2 ＝ 8
（4）1100(2) − 0011(2)12 − 3 ＝ 9

手順確認問題2　筆算

（1）0011 ＋ 1001繰り上げあり
繰り上げ 1 1 0 0 1 1 ＋ 1 0 0 1 ----------- 1 1 0 0
  • 右端：1＋1＝0、繰り上げ1
  • 次：1＋0＋（繰り上げ1）＝0、繰り上げ1
  • 次：0＋0＋1＝1
  • 左端：0＋1＝1
解答（1）
1100(2)

検算：3＋9＝12。12＝8＋4＝1100(2)

（2）0111 ＋ 0001繰り上げが3回続く
繰り上げ 1 1 1 0 1 1 1 ＋ 0 0 0 1 ----------- 1 0 0 0
  • 右から：1＋1＝0 繰り上げ、1＋1＝0 繰り上げ、1＋1＝0 繰り上げ、0＋1＝1
  • 0111 は 7。＋1 すると 1000（＝8）になる
解答（2）
1000(2)
（3）1010 − 0010借りなくて済む
1 0 1 0 − 0 0 1 0 ----------- 1 0 0 0

右から 0−0、1−1、0−0、1−0。どの桁も借りない。

解答（3）
1000(2)

検算：10−2＝8＝1000(2)

（4）1100 − 0011借りが2桁続く

右端の 0−1 ができない。その左も 0 なので、さらに左の 1 から借りる。

もとの上の数 1 1 0 0 借りたあと 1 0 1 (2) 引く数 − 0 0 1 1 ---------------------- 結果 1 0 0 1
  • 22 の桁の 1 を、右へ貸すので 0 になる
  • 21 の桁は借りたあと 2 になり、さらに右端へ 1 を貸すので残るのは 1。そこから 1 を引いて 0
  • 右端は借りて 2 になり、2−1＝1
  • 左端の 1 はそのまま 1−0＝1
解答（4）
1001(2)

検算：12−3＝9＝8＋1＝1001(2)

確認問題2　解答まとめ

問題確認問題4

補数を使って、次の4ビットの減算をする。引く数の補数を足して、桁上がりの 1 は捨てる。 確認問題2の（3）（4）と同じ式なので、筆算の答えと一致するはず。

式
（1）1010(2) − 0010(2)
（2）1100(2) − 0011(2)

手順確認問題4　減算を加算に変える

（1）1010 − 0010

引く数 0010 の補数を先に求める。

0010 を反転 → 1101 1101 ＋ 1 → 1110 ← 0010 の補数 1010 ＋1110 ------ 11000 左端の桁上がり 1 を捨てる → 1000

検算：0010＋1110＝10000。1010−0010 の筆算も 1000。

解答（1）
1000(2)
（2）1100 − 0011
0011 を反転 → 1100 1100 ＋ 1 → 1101 ← 0011 の補数 1100 ＋1101 ------ 11001 左端の桁上がり 1 を捨てる → 1001

確認問題2（4）の筆算 1001 と一致する。

解答（2）
1001(2)
確認問題4　解答まとめ
（1）1000(2)
（2）1001(2)

問題確認問題5

10進数の −2.5 を、32ビットの浮動小数点数（IEEE 754）で表す。 並びは例題5と同じで、符号 1ビット・指数 8ビット・仮数 23ビット。

例題5（＋0.625）の型

  • 2進数にして、1.×× × 2指数 の形にする
  • 符号：正は 0、負は 1
  • 指数：指数にバイアス 127 を足して、8ビットの2進数にする
  • 仮数：いちばん左の 1 を省略して、残りを 23ビットにそろえる

手順確認問題5　−2.5 を32ビットにする

① 2進数にして正規化する
2.5 ＝ 2 ＋ 0.5 ＝ 21 ＋ 2−1 ＝ 10.1(2) 小数点を左へ1つ動かして 10.1(2) ＝ 1.01 × 21 符号は負なので −2.5 ＝ −1.01 × 21
② 符号部

負の数なので 1

③ 指数部
指数は 1 1 ＋ 127 ＝ 128 128 ＝ 10000000(2) （8ビット）

例題5は指数 −1 だったので −1＋127＝126＝01111110。今回は指数が正の 1。

④ 仮数部
1.01 の先頭の 1 を落とす → 01 右側を 0 で埋めて 23ビット 01 00000 00000 00000 00000 0 ＝ 01000000000000000000000

符号 指数 仮数

1 1000 0000 0100 0000 0000 0000 0000 000
1 10000000 01000000000000000000000
確認問題5　解答
1 10000000 01000000000000000000000

戻し算：指数 128−127＝1、仮数は先頭に1を戻して 1.01。 1.01 × 21＝10.1(2)＝2.5。符号が 1 なので −2.5。

チェック迷いやすいところ

  • 補数は「全部反転しただけ」では足りない。反転したあと 必ず 1 を足す
  • 0000111 は 7ビット。先頭の 0 を消すと桁数が変わって補数がずれる
  • 補数の減算では、足し算の結果の左端に出た 1 を捨てて、元の桁数だけ残す
  • 浮動小数の仮数は、小数点の左にある 1 を書かない。01 の「0」を落とすと 2.5 じゃなくなる
  • 負の数でも指数部はそのまま。符号部だけを 1 にする（指数にマイナスは書かない）
