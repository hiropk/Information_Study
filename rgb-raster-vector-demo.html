DEMO 1 光の三原色（RGB）

ディスプレイは R（赤）・G（緑）・B（青） の明るさを 0〜255 で混ぜて色を作る（加法混色）。 スライダーを動かして、CSS の rgb() / カラーコードがどう変わるか見てみよう。

CSS: rgb(34, 163, 145)
カラーコード: #22a391
約1677万色のうちの1色
加法混色（CSS の mix-blend-mode: screen）
  • R + G → イエロー
  • G + B → シアン
  • R + B → マゼンタ
  • R + G + B → 白

1画素あたり R/G/B 各8ビット → 合計24ビットフルカラー（256³ = 16,777,216色）

DEMO 2 ラスタ形式 vs ベクタ形式

左は画素の集まり（ラスタ＝ペイント系）、右は数式・座標で描く図形（ベクタ＝ドロー系）。 同じ「円＋星」を拡大してみると、ジャギーの違いが一発でわかる。

ラスタ向き：写真、細かい陰影のある画像。
データ量は画素数×色深度に比例しやすい。
ベクタ向き：ロゴ、アイコン、図形、地図の線。
中心座標・半径などの数値だけなので小さく保てることも多い。
